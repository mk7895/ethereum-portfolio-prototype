# Archived Ethereum Testnet Prototype

An educational prototype developed to explore React/Web3 integration, MetaMask
wallet connections, Solidity contracts and Truffle deployment on an Ethereum
testnet. The project is archived, incomplete and unsuitable for deployment or
use with real funds.

## What it explored

- wallet connection and testnet transactions;
- Solidity token and portfolio structures;
- contract deployment and ABI integration;
- interaction between a React interface and Ethereum contracts.

Credential-bearing and unsafe backend files are intentionally excluded. Any
credentials previously associated with the prototype should be considered
revoked.
